Add `.sn-callout` for notes and warnings, `.sn-code` for a code block with a filename and copy button, and `.sn-terminal` for a window frame around a session or screenshot. React gets `Callout`, `Terminal` and `CodeBlock` (from `@snowztech/ui/client`). In static HTML, an empty `data-sn-copy` inside `.sn-code` copies the block's code.
